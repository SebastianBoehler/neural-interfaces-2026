# F-C4 — Balance the actual neural refit's class weight

Cap250 minimizes confidence-weighted hard-label cross-entropy at each of its 20 Adam updates (five per family), alongside the original invariant-augmentation KL. A class with more high-confidence pseudo-labels can dominate the cross-entropy even though the official metric weights task recalls equally. At each genuine pre-recognition refit, sum the stock confidence weights by the latest pseudo-class. Multiply every weight in a represented class by `clip(sqrt(mean_present_class_mass / class_mass), 0.5, 2)`, then rescale all weights to recover the original total. Keep the latest labels and rank within each class. The anti-balanced control inverts those factors before the same final normalization. Absent pseudo-classes get no new labels. All model inputs, augmentation, KL, Adam steps, refit timing, recognition stop and downstream stages remain stock. F-C3 is a separate rule that preserves each class's weight. It stays excluded from every F-C4 arm and its result cannot alter this registration.
