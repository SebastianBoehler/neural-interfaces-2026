# F-C1 — Separate the count prior from chain confidence

The count filter uses squared chain probabilities both to infer prior class counts and to emit a decision. That doubles the current EEG evidence relative to the count prior, although its original analyses measured one tied exponent on an older chain. In cap250, this also controls the scale at which the count prior and personalized EEG readout compete. Test changing the relative scale only where the original EEG latch enabled the count model. The primary arm keeps stock histories and emits `normalize(p * prior)` instead of `normalize(p² * prior)`. The history arm also uses unsquared probabilities to update the count and hypothesis states, isolating whether mistaken confident pseudo-labels accumulate in the count state. A confidence control emits `normalize(stock_probability ** .5)`, matching the primary arm's current-window exponent but halving its count prior. The stock arm leaves everything unchanged. Before the latch all arms return the untouched output. The earlier §455e applies before the latch and stays out of this experiment.

**Prediction and decision.** Against stock, predict primary +0.10 pp (80% prior −0.16 to +0.35). Against the confidence control, predict primary +0.08 pp (−0.12 to +0.28). Predict history minus primary +0.03 pp (−0.16 to +0.23). Positive lower 80% bounds support each contrast, an upper bound at or below zero refutes a positive effect for that contrast, and overlap leaves it undecided.
