## What the worker ran

The cap250 package projects one standardized TangentCore output onto one PCA256 basis. RouteB passes all 256 coordinates to the personal head and the first 128 to TSEM. The package exporter checks that the first 128 RouteB columns are exactly the TSEM columns. The legacy §431 replay uses two independently fitted coordinate views. That difference was measured in [D-EArT](../tail/result-18nov.md).

The §321 P04 and P10 source-fit archives each contain one common basis. Their independent native-window banks and fitted personal contexts both bind the same source-fit SHA. P04 has 2,278 source rows including 189 own visit-1 rows, with 377 own later rows held. P10 has 2,270 source rows including 192 own visit-1 rows, with 385 held.

Both modes called the actual cap250 ZIP's RouteB with fixed, authenticated D-EArT gate tuples, outer mixture, core posterior, ocular scores and event features. The split control injected the distinct TSEM coordinates at the live TSEM boundary and restored the legacy source head and prior. The shared mode used the recorded source-fold head and prior with the native PCA128 slice. It regenerated the PCA256 input from EEG using the actual pinned TangentCore. The stage comparison includes the change in the paired fitted representation, head and prior. The upstream inputs were held conditional on the selected D-EArT arm.
