# Stock-protected FBLight ZIP reference

The experimental reference embeds the exact measured native full dual-tail selector and both of its dependencies in one official `submission.py`. It authenticates the three sources from their immutable revision, preserves all 38 non-code assets, and uses the official reset and one-window interface. The two independently rebuilt archives match byte-for-byte.

On the real recognized P10 and warm unrecognized Scherer G prefixes, all 62 selected classes and every checked stock, alternate and chosen posterior matched the measured native implementation bitwise on CPU. Pristine and previously active copies, and explicit session reset after a different fixture, reproduced the first output. Optimizer work was 0 and 40 steps and the selector used the alternate on 0 and 11 windows. The checker opened no labels.

This full dual-tail ZIP is a parity reference. The original [RTX paired timings](../cap250c21_gate/native/README.md) measured this algorithm at 1.186× stock on G and 1.182× on P10, outside both preregistered timing bounds. Retirement and shared covariance are measured separately.
