# F32 · Concurrent motor-imagery supervision with isolated normalization

Registered 19 November 2026 before fitting. F6 exposed a weaker chronology encoder to an external motor objective before PROTEUS fine-tuning. §317 kept a private Shin word-generation head during population-BN fitting. Its 53% whole-decoder controls and seed-dependent effects leave the strong raw motor-specific case open. F32 asks whether concurrent motor supervision improves the exact S1C waveform body when the external task's normalization and head remain private.

## External data and terms

Use the original three F6 shards of EEG Motor Movement/Imagery Dataset v1.0.0, subjects 1–30. Gerwin Schalk and colleagues, PhysioNet (2009), DOI 10.13026/C28G6P. They contain 5,220 official-shaped 41×480 µV windows with all sensors measured, 174 per person across six imagined runs, no interpolation. The existing export uses MOABB's imagined-only default, run-aware left/right/both-hands/both-feet/rest, documented exporter and exact channel order. Baseline runs are outside this export. The original 41×480 PROTEUS input remains unchanged. The auxiliary reads just the first two native pooled seconds and requires the actual FIR influence to end before the three-second imagery interval, with a real tail-perturbation canary. Each corpus uses its own training scale.

The versioned source is publicly available under Open Data Commons Attribution v1.0. This experiment uses data files privately within the user's existing cluster allocations. It records the corpus, hashes, preprocessing, attribution and compute for any future method declaration. No submission or publication is part of this run. ## Matched training and decision rules

- Compare exact F16 hard, joint motor and detached motor. Draw forty external rows on a fixed private tape per original PROTEUS optimizer step, with eight rows per motor/rest class from distinct people within each class. The fixed native spectral bank and native trainable spatial convolution read the same external rows in both arms. A separate affine BatchNorm layer with no running statistics sees only external activations from the first two seconds. Apply native SiLU and two native log-variance pools. A private 576→5 head receives the external labels. The native PROTEUS loss and updates remain original. Add 0.25 × external CE in both arms. Joint propagates the auxiliary into the shared spatial projection. Detached blocks that gradient before the private normalization and head. Optimize the same private state and same exposures. All native SessionBN writes and original normalizer parameters remain unreachable from the auxiliary. The detached native fitted state must match exact hard. Only the original 347,903-trainable native three-class state reaches held inference.
- Keep the same official fit-excluded nine-person PROTEUS source, original 40 epochs, seeds 0/1, source batches, scaling, class weights and AdamW/OneCycle. Forecast bounded joint minus detached +0.75 pp [−0.75,+2.25] and motor recall +1.8 pp [−1.4,+5.0]. Detached minus exact hard is exactly zero. Support each gain with positive paired 80% people/order lower bounds in both seeds and refute it with nonpositive uppers in both. Otherwise undecided. Official whole held-new balanced accuracy on ten people × eight orders. Report ordinary inference, P04/P10 and three individual class recalls.
- Real four-epoch H100 P01 smoke must verify corpus source, all external count/tape hashes, private state activity, zero external gradient through the detached native path, active gradient through the joint path, exact native buffer and affine isolation during actual auxiliary calls, byte-exact hard checkpoint and detached state. Ensure authentic three-second geometry, auxiliary task learning (final fixed source CE below chance log(5) on both) and complete unchanged native optimizer updates. Before release run independent Galvani real held smoke with strict native load, exact first-window/reset, causal prefix, held-label separation and bitwise hard/sham decisions. Then twenty matched six-minute source fits and corresponding CPU holds, both at up to four concurrent. Seal all held decisions before opening labels. No package and no quota use.
