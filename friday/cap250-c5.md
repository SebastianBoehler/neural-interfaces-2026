# F-C5 — Compute CSP features only when the decoder consumes them

Cap250 computes eight OAS band covariances for every window until recognition. Its personalized refit only reads the highest-confidence half of the earlier windows in each pseudo-class, with a minimum of three. Its live reader starts at zero-based age 90. The historical returning bank records zero personalized outputs in all 32 routed streams. The ordinary A100 replay recognized all 14 public streams at age 10. This suggests that eager covariance work is spent on windows no fit or readout consumes. §369 changed the refit schedule and saved 4.1% of stage time. §408 pruned the separate count detector. This experiment preserves every original refit and changes when the personalizer computes covariance.

Retain a private copy of each delivered raw window until the original refit selector chooses it or the current window enters a live personalized readout. Evaluate the original OAS and band filters once at first use and memoize the covariance. Pass the exact selected features, original hard pseudo-labels and confidence ordering to the unchanged CSP/LDA operations. Use the stock recognition stop, warm-up, refit boundaries, count stage, weight and emission. A failed single-class refit consumes no features. On recognition, discard unresolved windows with the rest of the personalizer. There is no access to future windows or label metadata.
