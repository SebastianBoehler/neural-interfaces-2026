# F30 · Learn source-person transfer with a temporary supervised head

Registered 19 November 2026 before fitting. §220 trained raw FBCNet with single-session predicted class-marginal balancing and lost in that form. §395 trained a separate calibration policy on nested sources. §405 learned weights on fixed spectral kernels through person-held ridge problems. F28 transferred teacher geometry. F30 tests whether the existing raw decoder learns more transferable task features when a temporary supervised update supported by one source person must help classify a different source person. No teacher, external EEG, episode reshuffling, added inference parameters or test-time updates.

- Keep each original two-chunk source batch and native weighted hard CE. An extra episode is eligible when the two 32-window chunks come from distinct people and each side contains four distinct rows in each task. For each class choose the first two unique rows in original stochastic chunk order as support and the next two as query. Each side contributes six labeled support and six disjoint labeled query examples. Both training arms use all of the same original examples, optimizer steps and label distributions.
- Center and L2-normalize the original 1,152 waveform features per row for the extra objective only. Start a separate temporary bias-free affine residual at zero. Compute a single exact cross-entropy gradient update on its support, with step size 2.0. Add the residual to the ordinary native logits on queries and apply 0.25 × query CE in addition to the original native loss. Cross uses the opposite person's support. Within uses the same person's other rows and is the matched comparator. Both arms differentiate through the support and query. Both discard the temporary readout after each episode and preserve original normalization writes and raw inference.
- Compare both against exact F16 hard. Keep 40 epochs, seeds 0/1, original fit-excluded nine-person cohorts, class weights, source scale, AdamW/OneCycle and untouched held EEG. Forecast bounded cross minus exact hard +0.80 pp [−0.65,+2.25], and cross minus within +0.45 [−0.80,+1.70]. Require positive lower paired 80% people/order bounds at both seeds for each supported contrast. Nonpositive uppers on both refute. Otherwise undecided. Score original official equal-cell scheme-balanced whole-decoder accuracy over ten held-new people and eight orders. Report ordinary inference and P04/P10. A fixed first-six eligible source episode diagnostic forecasts better cross-query CE for the cross arm than within. The diagnostic alone gives no held gain.
- On real four-epoch P01 smoke require at least 15% eligible original steps, identical hashed support/query tape, a genuine independent autograd reproduction of the temporary step within 2e−5, zero-step exact logits, source gradients on both support and query features, true native updates, zero fixed-feature gradients and exact F16 hard bytes. Protect original running statistics and model weights from the extra source-only diagnostic. Independently verify ordinary/bounded first-window equality, exact interleaved reset, strict prefixes, complete blind held coverage and exact hard decisions. Then run twenty paired H100 tasks followed by corresponding Galvani held tasks, each capped at four concurrent with six-minute allocations. No stack, release, or upload.
