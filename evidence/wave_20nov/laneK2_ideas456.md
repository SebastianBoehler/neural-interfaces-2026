## Features (one CPU extraction `feat_k2.py`, 4 s window = 480 samples at 120 Hz, from `data/proteus_windows.npz` X)
Bands (the chain's own band constants were not located, so defined here, stated): theta 4-8, alpha 8-12, mu 8-13, beta 13-30, broad 4-40 Hz, 4th-order Butterworth zero-phase within the window. ROIs: central {Cz,C1,C2,C3,C4,CPz,CP1,CP2}, frontal {Fz,F1,F2,F3,F4,AF3,AF4,FCz}, lateral {C5,C6,CP5,CP6,TP7,TP8,P5,P6}. Everything is a function of the one delivered window.
- Idea 4: v1 / v2 = 9-vectors (theta, alpha, beta x three ROIs) of log band power on samples 0-239 / 240-479, standardized with source statistics. Per held-out person j, fit on the other nine people (labels enter only this frozen fit): shared ridge map B0 (v1 -> v2, intercept, penalty 10), class maps B_k = B0 + ridge on class-k rows toward B0 (penalty 10), residual covariance S_k = 0.5 class + 0.5 pooled + 1e-3 I; candidate log-likelihood ll_k = log N(v2; B_k v1, S_k). At scoring: the top two classes a, b of the post-TSEM raw posterior, centered ll over {a,b}, logit += clip(0.15 x centered ll, -0.5, +0.5), other class untouched. Controls: `marg` = class-specific Gaussian on v2 alone (same shrinkage, same 0.15, same clip); `perm` = the conditional model refit with v2 permuted within source (person, session, interface) and class, three permutation seeds (mean reported; each seed also listed).
- Idea 6: per band b in {mu, beta}: N_b, D = sample covariances (41x41) of the band-filtered / broad-filtered window; whiten by D (eigendecomposition, keep eigenvalues > 1e-8 max), eigenvalues of W (N_b + 0.001 D) W^T, log, sorted, 4 lowest + 4 highest per band = 16 features (`gen`). Control `abs`: same size from the eigenvalues of N_b + 0.001 D (absolute, not mixing invariant). Source-only ridge multinomial logistic (L2, C = 1, standardized, nine other people); centered log evidence x 0.10 added to the raw logits (no clip). Invariance gate before any scoring: on 200 real covariance pairs transformed by fixed random invertible M (condition < 20) `gen` must agree to 1e-6 relative and `abs` must not; the job fails otherwise.
- Weight scale s in {0.5, 1, 2} x the spec weight is run as arms (selection below); the spec weight s = 1 is the reported arm.

## Idea 5 (feasible class prior in the SessionEM responsibilities)
Wrapper around the stock SessionEM step: output posterior and stock rebalance unchanged, only the responsibilities stored for the template fit (`e.B[-1]`) are replaced by resp = normalize(pre-rebalance mix posterior x pi / (1/3)), pi from past votes. Source statistics from the other nine people's pre-rebalance mix posteriors (fit-excluded, labels only here): hard-vote confusion C_h (3x3), high-margin votes (margin >= source median) C_m (4x3 incl. a no-vote category), class frequencies. At delivered count n >= 40, every 20 calls, from votes strictly before the window: feasible grid (step 0.01) {pi: |q_c - (C pi)_c| <= eps_n for all categories of both vote sets}, eps_n = sqrt(ln(2 x 7 / delta) / (2 n)), delta 0.2; active iff nonempty and some class range < 0.20, then pi = feasible point closest to uniform, else uniform (inactive). Arms: `uniform` (pi = 1/3: responsibilities = mix, the control with identical template updates), `feas` (delta 0.2), `feas50` (delta 0.5, beyond-spec sensitivity, labelled), `oracle` (pi = true session class frequency from labels: the ceiling, labels used only here), and stock = base. Diagnostics: active/infeasible prefix counts, L1 error of pi vs the session true frequency, feasible vs uniform, by prefix age (40-80, 80-120, 120+). Scherer orders 71000/71001: not scored here (no Scherer replay harness in this lane; stated, not silent).
