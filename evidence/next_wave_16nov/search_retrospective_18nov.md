## Where new evidence would change our thinking

1. **Separate task evidence from person, device and session cues.** We have cross-corpus results, including a real exact-package Scherer test. Scherer uses 19 native and 22 reconstructed channels and different tasks and people. Reserve distinct evaluation people before fitting or choosing another cross-corpus readout. Measure corrections by class and interface alongside the actual three-class decision. Keep the public P04/P10 returning checks separate. [External evidence](lunch_qualification385.md)
2. **Broaden the training signal.** §277 already tested contrastive and masked pretraining. Its first comparison used 74,617 external windows but a weak linear probe. §389 tests whether task-specific dynamics predict the next EEG sample. §391 tests transitions among local amplitude ranks. Their features differ, but both ask about local temporal dynamics. The next exploration slot should change the data or supervision axis, such as testing whether a learned WORD/SUB contrast transfers across studies, with native-channel and matched-capacity controls. Record earlier §317/352/356 comparisons before choosing that design. [Earlier coverage review](solution_space_review_17nov.md)
3. **Measure what evidence can change a decision.** §383 showed that additional correct predictions can be canceled by new mistakes. §386 found that fourfold greater training-row turnover gave almost no improvement. §390 tests whether exchanging only borderline examples preserves useful high-confidence rows. §392 tests whether an explicit-normalization decoder can identify which A6 corrections survive in the complete stack. The two A6 variants share initialization, so agreement could just conserve their shared errors. [Turnover evidence](turn386.md) · [Whole-decoder evidence](joint382.md)
4. **Budget by scientific question.** Count a smoke, controls, seeds, array shards and a collector as one question. For the next block allocate two distinct questions to exploration and two to refinements. Track actual CPU, A100 and H100 time separately. Use the same full scorer on identical rows and orders; use the original streaming path to validate promising changes. A fast replay reduces evaluation cost. It cannot repair repeated participant selection or establish a sealed gain.
