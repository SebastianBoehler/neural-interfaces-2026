# First-pass mechanisms checked against the 17 November evidence

The scoring unit is a participant/session/interface cell. The evaluator averages class recall inside each cell, then averages cells. A training loss proportional to inverse class count **within each cell**, with equal total mass per cell, corresponds to this averaging when all classes occur. Difficulty weighting is an additional hypothesis. At inference the interface, participant and gold label are unavailable. Only delivered EEG from the current session can supply context.
