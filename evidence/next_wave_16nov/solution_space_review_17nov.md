## Proposed decisions and bounded comparisons

1. **Train for complementarity.** The §371 task-pair and true-class/interface check is complete. Its two largest SUB↔WORD directions contain 44.6% of available rescue and both lose under blind switching. Keep delivery age and person-level concentration for a source-only follow-up if needed. Start with one pre-registered three-way person split. Train the base and all upstream priors on the first group, learn a waveform member on the second group's incumbent errors, and compare complete systems on the untouched third group. Match topology, total weight, update count, and regularization to ordinary cell-balanced fitting and one confidence-based weighting control. The known §339 SOURCE8 assets cover member fits, so a full nested incumbent replay needs separate validation. If the base assets are incomplete, the bounded first pilot is an explicitly scoped diagnostic. Plan at most two A100-hours for the source pilot. The later full-system comparison has provisional prior +0.3 pp [−0.3,+1.0]. Judge it by paired incumbent failures recovered at matched standalone accuracy. A reliable loss in the complete system sets aside this form. [§371 diagnostic](../../docs/LEDGER.md) · [§339 asset scope](calibration339_full_handoff.md) · [Nested producer lineage](branch_selector363.md)

2. **Test a complete source-trained session model.** Learn a causal population-to-session correction jointly with a strong per-window representation. A small permutation-invariant encoder estimates session style from preceding embeddings. The current-example head predicts with that state and learns its own uncertainty for adaptation. Offline training may score later points in shuffled source sessions. Match capacity, supervision, seeds and cost against a current-only head that sees the same current features. Score the complete model against the strongest held baseline across the same orders. Before expanding, require source-only optimization, a real earlier-prefix effect and invariance when the same prefix set changes order. Start with one source smoke and one bounded paired source pilot. The initial goal is to reach within 2 pp of the strong complete control with a positive paired effect over the matched static decoder. This tests joint adaptation and representation where the four-person head kept the original body fixed. [Prefix pilot](causal_prefix359.md) · [Permutation-invariant architecture source](https://proceedings.neurips.cc/paper_files/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html)

3. **Reserve RL for a measurable sequential decision.** With the already verified native control, choose one action, such as hold versus refit, with a hard measured work cap. Compare a fixed cadence, a one-step supervised policy and a short look-ahead using labeled offline source rollouts at the same work. Whenever an action changes state, recompute its subsequent trajectory. Run no sealed reward or exploration. Advance to multistep learning only if look-ahead supplies repeatable headroom across source episodes, with subsequent evaluation on held people and orders. The current fixed schedule shifts leave accuracy near zero. A larger CUDA framework and repeated reward variants should wait for a live mechanism.
