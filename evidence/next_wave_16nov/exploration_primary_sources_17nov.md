## Distinct experimental questions

### 1. Spend compute where it changes the decision

**Closest evidence.** §276 studied static seed/family reductions. §320 ranked already-computed forward branches: +1.017 points versus uniform on one exposed person, with the 60.115% identity control below the preregistered 68.60% quality bound. §316 learned causal step sizes on a common anchor: its scalar arm improved over the fixed update but remained below the complete control. Neither comparison establishes the value of buying an expensive forward pass or committing a persistent refit. [Ledger §§276, 316, 320](../../docs/LEDGER.md)

**First comparison.** For a strong base and one expensive current-window action, score both actions on nested, cross-fitted source folds. Train a small selector to predict the incremental value of the expensive action, then evaluate always-cheap, always-expensive, fixed cadence where applicable, a margin gate at matched measured cost, the learned selector, and an oracle. The selector receives only information available before calling the expensive action. Start with cached branches whose choice leaves downstream state unchanged, or rerun the complete state machine for every arm. A cache of predictions from one policy cannot evaluate another policy that changes future state.

For cells containing all three classes, each correct prediction contributes `1 / (C × 3 × n_cell,class)`, where `C` is the number of evaluated cells and `n_cell,class` is the number of rows for that class in its cell. Score corrections and newly introduced mistakes. If a cell lacks a true class, use whole-cell scorer differences, since predicting the absent class can change the metric's denominator. Use these weights and labels in offline training and evaluation. At inference every call emits a label, and a deterministic session-local work cap and worst-case worker measurement enforce the budget. FrugalML provides a primary example of a budgeted cascade on other tasks. It gives no estimate of A100 savings here. [FrugalML](https://papers.neurips.cc/paper_files/paper/2020/hash/789ba2ae4d335e8a2ad283a3f7effced-Abstract.html) · [Official metric implementation](https://github.com/neural-interfaces26/2026-competition/blob/main/benchmark_utils/metrics.py)

**When reinforcement learning has a question to answer.** For an independent per-window choice all candidate outcomes can be observed in offline labeled replay. This supports cost-sensitive supervision with full information. A contextual bandit assumes the learner sees the reward of only its chosen action. Sealed evaluation supplies no reward, and predictions cannot change the incoming EEG. An update decision can change the decoder’s future parameters, however. For `hold` versus `refit`, use labeled source-session rollouts with label-free policy observations to compare fixed cadence, a greedy selector and short look-ahead at matched cost. The look-ahead gap measures possible value in sequential control; compare any reinforcement-learning method against those baselines. The deployed policy can receive only label-free session-local inputs. [Agarwal et al., contextual bandits](https://proceedings.mlr.press/v32/agarwalb14.html) · [Official adaptation contract](https://raw.githubusercontent.com/neural-interfaces26/2026-competition/main/codabench/pages/scientific_faq_bci.md#streaming-and-adaptation)

### 2. Learn the decision from an unordered delivered prefix

**Closest evidence.** §323/332 found roughly four points of individual-decoder benefit from adapting normalization. §339 ran the full new-person consumer with calibration; all six intervals span zero. §316 changed strong-core head updates while keeping downstream features and routing. §334's tested generative decoder lost to its own static control. These outcomes leave open whether an adapted representation helps a stage trained to use that representation. [State and §339](../../docs/STATE.md) · [Earlier coverage audit](fresh_search_coverage_16nov.md)

**First comparison.** Train a compact causal set encoder on shuffled, cross-fitted source episodes. Aggregate frozen embeddings in additive summaries of previously delivered windows, then predict from the current embedding and the prefix summary. Preserve baseline current-window features and use a trainable readout with a verified no-prefix control of matched capacity. The order of elements inside a fixed prefix can be invariant while the model still uses only the information available at each prediction. Vary prefix composition under the pinned shuffle schemes and check exact prefix isolation. Compare to the complete incumbent and a matched static decoder, then verify the replacement of the resulting session stages and routing wherever the design uses them. Deep Sets supplies the pooling architecture. Its results establish no EEG transfer. [Zaheer et al., Deep Sets](https://proceedings.neurips.cc/paper_files/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html)

### 3. Test relations in a decoder that already works

**Closest evidence.** §313 added cross-spectral features through the current pipeline without an established gain. §355 is already complete and supersedes the pending line in STATE. The learned lag model scored 42.742% versus 39.338% for the instantaneous control. All four complete decoders scored below 55%. Equal parameter counts leave the zero-lag matrix symmetric and the lagged matrix asymmetric, so the contrast also changes effective feature rank. §354's task/style factorization lost to the strong raw decoder by 7.44 points on three exposed people. The comparison with the matched factorizer remains undecided. [§355 results](relations355_results.md) · [§354 scope](factorization354.md) · [Ledger](../../docs/LEDGER.md)

**First comparison.** Keep the strong raw EEG alignment, normalization and readout. Change the relation branch before channels are compressed. Match both width and effective degrees of freedom between time-aligned and time-shifted controls. Include a channelwise-marginal-preserving disruption of the cross-channel relation. Only extend to held-person replay once the same-code unmodified control matches the strong reference and the extra signal path is demonstrably active. A whole-system test should show whether the new relation corrects errors shared by the existing members. ### 4. Use external people to test transfer before adding more data

**Closest evidence.** §290's flat 69.29% core beat the tested regional/hierarchical and pairwise heads by 2.12–16.83 points. §317's matched auxiliary transfer contributed +0.0023 official points over the no-transfer auxiliary arm in the complete new-person system, with its interval spanning zero. §352 showed a frozen PROTEUS-only 19-channel binary decoder discriminating WORD/SUB on Scherer 2015. Full covariance reached 59.03%, versus 53.26% for diagonal power, with eight of nine people improving. The contrast also increases dimensionality tenfold. Scherer measured word association and subtraction in a distinct clinical cohort. This supplies an external condition-discrimination instrument with cue, protocol, acquisition, and cohort limits. §356 then tested the reverse transfer through a fixed terminal correction. It scored 75.37% versus 75.72% with the PROTEUS-only correction and 76.22% for the untouched chain. This sets aside the tested fusion and leaves the external diagnostic question open. [§290](../../docs/LEDGER.md) · [§317 full-system scores](aux317_chain_results.txt) · [§352 sources and results](external_pair352.md) · [Scherer et al.](https://doi.org/10.1371/journal.pone.0123727) · [§356](external_binary356.md)

**First comparison.** Use a fixed same-width covariance sketch and a matched diagonal/power control, with coherent current-decoder readout and source-only selection. Test whether improved external WORD/SUB discrimination predicts corrections to the incumbent's held-person WORD/SUB confusions. Keep the external instrument outside training in this first test. If a later study adds matched external supervision, use separate external people to evaluate it and keep the three-class PROTEUS comparator. Report nuisance sensitivity and error overlap before adding another ensemble member.

## Evidence required for a decision

- Use an identical model and action path to compare native and Python performance. Measure the cold and warm end-to-end worker distributions and peak memory under the one-window interface. Record refit counts and timing alongside decision parity. Component timing cannot allocate contest budget on its own.
- Register one comparison per mechanism with source hashes, numeric hypotheses, expected cost, and a refutation rule before scoring. Use the official metric and scorer, confirm no-change controls and pinned orders, and check reset, deepcopy, interleaving and prefix behavior. Require evidence that the changed option actually runs.
- Report new people, P04 and P10 returning sessions, the 57/43 sensitivity proxy, and intervals resampling people and orders. Repeated selection on 10 public people limits confirmation. Independent external testing is informative about transfer in its own setting. A new component requires qualification with the actual stages that consume it. A whole alternative requires whole-decoder scoring.
