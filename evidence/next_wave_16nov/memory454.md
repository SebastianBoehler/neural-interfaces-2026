# §454 and §454c · Learned spectral session memory

On 18 November, §454 registered two causal session readers. The first learns whether earlier windows resemble the current query and averages their learned three-class values. The second reads a learned twelve-dimensional second-moment matrix. Both estimate a correction to the same frozen historical full-system output used in §443.

§454c tests whether the first reader learns a more informative correction when source episodes have coherent channel-gain shifts and spectral tilts. The matched control presents the same marginal perturbations independently across windows. All held EEG stays untouched. No architectures, losses, integration constants, or thresholds depend on held outcomes.

## Instrument

Each model fits nine source people and evaluates the tenth. All arms use the same 28 official public cells and eight pinned orders. Only earlier EEG from the current session updates the actor. Subtracting the actor's source-average write at the same age preserves a zero correction on each session's first trial. A cyclic source-session donor tests the importance of genuine writes. The full-system scorer compares every stock label to the authenticated §443 decision bank, requires an exact zero-correction match, and writes a decision hash before opening held labels.

The primary comparator is historical B2_pool cap250 at 76.2793%, which used nine eye seeds. The staged package uses three. Public held-new-person outcomes do not establish returning-person, exact-package, or sealed accuracy.
