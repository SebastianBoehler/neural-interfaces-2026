# Data and transfer research — working evidence, 16 November 2026

Scope: Track 2 mental imagery, subtraction and word generation. Sources checked 16 November 2026. This note proposes research only; no data were downloaded, no model trained and no experiment scored for this note. Prior project results below refer to the cited historical code path and are not verdicts on different systems. `evidence/data_inventory_15nov/inventory.md` and `evidence/review_14nov/data_hunt.md` were read first. A file called `recentdata_hunts` was not located in the searched project and handover locations.

## Decisions and constraints

- The strongest verified external public, three-task EEG match located is Scherer/BNCI 2015-004; PROTEUS itself is the public target training corpus. It was already tested and was strongly negative for the tested core. I did not verify another matching, publicly accessible and licensed three-task EEG corpus. This is a search finding, not proof none exists.
- The central hypothesis is **source/task semantics and sensor/domain mismatch matter more than window count**. Evidence: matched-task Scherer itself loses several points, CMx7-MM and EEGMAT additions hurt the historical teacher chain, and a training-fold WORD-mean shift reduces Shin pooling harm. These are different experiments, not an isolated, controlled test of source count versus sample count. The project has not identified a causal bottleneck; measure corpus-held-out performance versus matched window-count controls before calling it one.
- Public source rest recordings add **training information**, if permitted. For a new-person fold, exclude all data of that person. For a returning-person fold, prior public sessions may be used where the protocol permits, but exclude held-out sessions and their rest. No separate rest recording for the evaluation session or target labels are supplied at inference. The model may only use the current and earlier **delivered** windows from the current session. [EDAPT](https://doi.org/10.1088/1741-2552/ae5689) updates on revealed true trial labels after prediction, so its results cannot justify that update here. Delivery can be shuffled, so adjacency does not establish acquisition chronology. The target receives no source/corpus ID. See [competition terms](https://github.com/neural-interfaces26/2026-competition/blob/main/codabench/pages/terms.md), [scientific FAQ](https://github.com/neural-interfaces26/2026-competition/blob/main/codabench/pages/scientific_faq_bci.md), `OFFICIAL_CONTRACT.md`, and `docs/STATE.md`.
- Evaluate a proposed component through the registered full system, including the routing and personalization that use it. Evaluate a complete alternative as its own system, with its own zero-change controls, pinned delivery orders and people-and-order nested uncertainty. No external result establishes a gain on the shipped v6.6 chain. Numeric historical differences below are percentage points unless otherwise stated.

## Rest, auxiliary tasks and information

A training-only corpus-specific head is a way to learn shared features without pretending source labels are target labels. It does **not** supply extra information during inference; inference still sees only target EEG windows and training-derived parameters. [Target-rest fine-tuning](https://pubmed.ncbi.nlm.nih.gov/39365711/) reports benefits on a different motor-imagery protocol, but relies on separately recorded target resting EEG. That input is not available here. Earlier target windows also cannot be presumed rest.

The broad idea of shared backbone plus source-private heads is **not new here**: `experiments/pretrain.py` implements it, and `experiments/cotrain.py` implements target/source joint training. `docs/archive/OVERNIGHT_2NOV.md` §T7 found joint auxiliary heads helped a single sinc member by +0.61 to +0.63, but an extra ordinary sinc seed was +0.65; seeds 6–11 reduced the claimed advantage to +0.35–0.37. Earlier `docs/archive/OPTIMIZATION_R10.md` R17 unified rest-anchored pretraining also worsened sinc, FBCNet and the tested R15 swap. Do not call generic multi-head training an untested improvement.

[Zhao et al.](https://proceedings.mlr.press/v97/zhao19a.html) give a counterexample: good source accuracy and an invariant representation do not guarantee target accuracy under class-conditional shift. This is theory, not proof of the cause of our observed losses. A separate [2026 workload study](https://www.techscience.com/iasc/v41n1/68334/html) reports source-private heads still lost 0.01–0.03 macro-F1 versus target-only, while task-harmonized class-wise mean alignment improved one direction; the strongest +0.047 figure is versus naive pooling, not directly the target-only baseline. Its workload datasets and protocol are different from this task. Class labels, montage, cue timing and recording setup differ together, so an adversary that removes corpus identity can also remove task information.

A narrower untested hypothesis is a source-private WG-versus-rest auxiliary objective with explicit person/corpus conditioning and a target-only three-way head. It must not turn unlabeled target classes into negatives. Compare against equal compute, extra target seeds and unconditioned private-head controls, plus source-label permutation. For new-person evaluation, hold out all recordings including rest of that person. For returning-person evaluation, permit prior public sessions only where the protocol allows, and hold out the evaluation sessions and their rest. Only a complete chain result answers whether it helps. Code-path warning: `experiments/pretrain.py --uda` calls `load_proteus`, which excludes P04/P09 only, not the arbitrary person held out by an all-person LOSO fold, and its alignment reads whole sessions. Do not reuse that option as strict unseen-person/causal evaluation without a fold-specific redesign. `docs/archive/WAVE10_3NOV.md` explicitly reports that its 10u diagnostic used this option and saw all eight then-dev people without labels; it calls that transductive. At production weight 5, lambda 0.5 was −0.09 versus the base pair; the selected maximum across weight settings was +0.22. Its transductive diagnostic is not a guaranteed mathematical upper bound or an honest unseen-person result. It was a different old teacher chain, not evidence against every later adaptation design. New public source domains may help; repeated windows from already used people cannot by themselves demonstrate domain diversity.

## Candidate mechanisms and adversarial checks

1. **Class-aware covariance correction — moderate implementation opportunity, uncertain upside.** [OSPDIM](https://arxiv.org/html/2608.05315) makes online symmetric-positive-definite feature adaptation robust to simulated class imbalance, using a recent FIFO buffer and gradient updates. It is evaluated on two binary motor-imagery datasets after artificial minority-class subsampling, not this three-class chain. Its 32-item buffer and five manifold updates per sample also need a real paired runtime measurement. Existing prefix normalizations, SessEM and personalization already cover adjacent ideas; historical R12 explicitly tested [T-TIME-style](https://arxiv.org/html/2412.07228) entropy and marginal-entropy updates, with all tested settings losing after the then-chain rebalancing (`docs/archive/OPTIMIZATION_R10.md`). An estimate that treats changing class mix as sensor drift can shift class-relevant geometry and damage a fixed classifier; invertible alignment need not destroy information. First diagnose prefix covariance versus true class mixture offline with labels explicitly marked oracle-only. If later tested, use only past/current windows, fixed offline-trained priors, no inferred class quota, an identity-bias baseline, and worst-order runtime. Class-conditioned covariance estimates may be unstable early and pseudo-label feedback can amplify mistakes. §281 tested CORAL w1, B1 and both at −0.069, −0.095 and −0.220 points; it did not test OSPDIM or §291's confirmed CORAL w10 form.
2. **Train-to-adapt — high conceptual upside, high overfit/engineering risk.** [MT3](https://proceedings.mlr.press/v151/bartler22a.html) meta-trains test-time updates on non-EEG tasks. Propose episodic training of a small bounded update on unlabeled delivered prefixes, with an outer loss on later labeled training-person windows. Randomize the actual delivery schemes, reset state per session and hold out people at both model selection and final evaluation. Compare update disabled, same-compute frozen head and ordinary self-supervised update. This is not the same as project §256, where an SSL-adapted auxiliary member fused into the chain lost 0.84 [−1.41, −0.27]. But train-inside-adaptation is not a new general concept here: §220 trained fbraw with balanced session episodes and eight unrolled bias updates. Its full older chain changed −0.10 to +0.16 across three bases, with returning-person losses in the member; that form did not meta-learn an unlabeled update against future training-person windows. §98 also trained an episodic causal transformer and scored 5–28% held-out-person accuracy, but the later code audit found its supposed small QR rotation can flip signs while passing its magnitude guard; the historical traces have not been inspected. Its failure is confounded and does not reject learned session models. §220 and §256 still lower the prior for related specific updates. Ten target people make model selection exceptionally noisy; no measured gain yet. Never train from held-out target labels or future windows.
3. **DEFT — scientifically relevant, expensive and unproven in our stack.** [DEFT preprint](https://arxiv.org/html/2610.14497) trains content/style branches with subject-aware losses, reporting subject-disjoint benefits on motor imagery, mental arithmetic and speech. The [released main command](https://github.com/wythedee/DEFT) defaults to ordinary shuffled batches despite the paper's subject-balanced description; published-run use of this command is unverified. Its REVE compatibility check is not this task. Local §280 REVE fine-tuning alone scored 55.3–55.8 and its base-ensemble marginal was +0.42 to +0.48 with intervals crossing zero; pretrained versus random initialization contributed +1.07 to that base-ensemble marginal. No full-chain gain was measured for this REVE form. The result is undecided, not a failure of foundation-model transfer. DEFT's content branch still retains high known-subject probe accuracy, so it is not demonstrably identity-free. Strong counterarguments: content/style may remove person-specific discriminative signal, and the measured full REVE cost is a deployment obstacle. The smaller local CBraMod provides a separate choice. Compare the same pretrained backbone, sampler and parameter-matched adapter; evaluate a complete decoder whole, or evaluate an added component through the complete incumbent. Subject identity is training-only. A standalone result is not a chain gain.
4. **Compact TabICLv2 on existing features — attractive fast offline probe, deployment risk.** [Original TabICLv2 paper](https://proceedings.mlr.press/v306/qu26a.html) and [authors' repository](https://github.com/soda-inria/tabicl) describe supervised in-context prediction over labeled source rows and test features; reported benchmark gains are generic tables. The source-context labels would have to come only from training people, never held-out test labels or future unseen windows. Even a fixed labeled-source example context or derived key/value cache has an unresolved competition-rule status: the FAQ does not explicitly classify it as learned parameters. Distillation into fixed weights avoids that specific ambiguity; clarification is required before assuming the original context can ship. About 44,000 core features exceed the official pretraining range of 2–100 columns, and §49 found a 512-PC projection lost about four points, so feature compression needs its own comparison. Strong static features, correlated windows and person imbalance may favor trivial subject signatures; group source context by person, match the total per-person rows and use held-out-person scoring. Benchmark a genuinely compact context against logistic regression, tree ensembles and existing chain heads on identical features, and report warmed A100 inference, peak memory and full packaged size. Fitting normalizers on the whole held-out session is transductive leakage; require a source-only or causal-prefix transform. Determine whether package caching persists across sessions before implementation; do not retain target data across session boundaries. Use official code/weights license and pretrained-data reproducibility rules, verify exact files. Current model is roughly 28M parameters, so a small training table is not a small neural network.

State-space models are not exempt from shuffle: [Bayesian online change-point detection](https://arxiv.org/abs/0710.3742) assumes meaning in sequential observations. Project §217/§251 already tried causal boundaries and got mixed order-dependent results. Delivery adjacency is not evidence of acquisition adjacency. A state-space proposal must learn an exchangeable prefix statistic or justify an order-valid latent state, reset at every session and be compared as a complete system. It need not reproduce incumbent personalization internally.

## Suggested next evidence, not authorized runs

Before code or jobs, choose exact models and preregister numeric predictions and refutation rules. Useful information per effort: audit held-out-person error and confidence against source-domain, class and prefix composition; compare equal-window/number-of-person and leave-one-source-out controls on already available data. For each chosen form, specify fixed-source and equivalent-baseline controls. Evaluate complete alternatives whole and component integrations through the incumbent. The corpus evidence currently favors testing mechanisms against mismatch over simply adding long, semantically different recordings. This is an informed prioritization, not a proven ceiling.
