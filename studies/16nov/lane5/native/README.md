# Lane 5 native backend

This C ABI uses LibTorch for tensor operators and autograd. It is not a dependency-free runtime. `build.sh` uses an existing PyTorch installation to locate headers and libraries; it downloads and installs nothing. On Galvani, build in a private directory with the existing GCC 12 C++20 toolchain and set its runtime library path. The final `.so` and every dependency must be validated in the actual worker image before packaging.

`api.h` is the ABI. Calls take CPU-contiguous float32 arrays; the implementation copies to/from the selected device. Integer class labels are int64 and person IDs int32. Arm IDs: 0 baseline parity, 1 temporal, 2 connectivity, 3 hybrid. The flat baseline parameter order is hidden weight, hidden bias, output weight, output bias. Head parity functions take already-normalized features and a supplied mask. `n5_predict` returns logits and does not change session state. `n5_step` returns current-window logits after any update from strictly earlier windows, then appends the current window. `n5_reset` restores the population anchor and clears the session; `n5_clone` owns independent copies. Checkpoints contain the population anchor and normalizers, not an online-session snapshot. Publication uses a same-directory temporary and atomic no-replace link; an existing destination fails.

New encoders divide by per-channel training-fold RMS without subtracting the mean, and append the 41 resulting channel means. The temporal encoder uses a 41→16 pointwise projection and three 16-channel depthwise convolutions with kernel lengths 15, 31 and 63. Their 48 log powers plus means give 89 features. The connectivity encoder learns an 8×41 spatial projection, forms five FFT-band real covariance matrices, retains eight log diagonal powers and 28 off-diagonal correlations per band, then appends means: 221 features. Hybrid concatenates both branches and one copy of means: 269 features. Each uses a 64-unit exact-GELU head and three logits.

Fit uses 60 epochs in production, AdamW 0.001/0.001, batches 128 and inverse person/class frequency weights. Hybrid consistency adds 0.1 times symmetric KL between clean and channel-gain-perturbed training rows. Minibatch and augmentation random generators are independent. `n5_fit_status` reports steps, cumulative symmetric KL, maximum connectivity-projection gradient and shuffle hash; `n5_consistency_grad` reports the added term's parameter-gradient norm on the first batch. Before each window at positions 40, 60, … the optional entropy update uses at most 64 earlier windows, three output-head SGD steps of 0.001, population-head L2 penalty 0.1 and a displacement cap of 0.1. Its objective is mean per-window entropy minus 0.1 times entropy of mean probabilities. These are whole-system research arms, not the pinned v6.6 package.
